### B.1 Rules (findings print as `file:line: [rule] message`, plus a GHA `::error` line, matching doc-gates)

| Rule | Fires when | Reported at |
|---|---|---|
| `must-unmapped` | A MUST/MUST NOT row is cited by no `Covers` cell in §13 (this includes a missing §13), and the baseline doesn't list it as `unmapped` | spec file : R row line |
| `must-untested` | Cited, but none of its T-IDs is echoed as `SPEC-xxx-Tnn` in a test source, and the baseline doesn't list it as `untested`. The message lists the T-IDs. | spec file : R row line |
| `echo-unknown` | A test source echoes `SPEC-xxx-Tnn` where spec xxx doesn't exist or has no Tnn row in §13. Blocking with no baseline, since the count is 0 today. | test file : line |
| `baseline-stale` | A baseline entry is no longer a gap, is not a MUST (renumbered, removed or downgraded), or its kind improved (`unmapped` but now only `untested`). The message says "remove it / run --update-baseline". | baseline file : entry line |
| `baseline-format` | Malformed JSON, a bad entry shape, a duplicate, or entries not sorted | baseline file : line |
| `baseline-grew` | Only with `--base-ref`: an entry that wasn't in the base commit's baseline, or `untested` → `unmapped` versus base | baseline file : entry line |

**Satisfaction rule:** a MUST is traced if at least one of the T-IDs that cite it is echoed. This follows CI/CD §5 ("a `MUST` with no linked test"). The stricter "all of them" is open question B-Q3.

**Echo regex:** `\bSPEC-(\d{3})-(T\d+[a-z]?)\b`. `SPEC-001-T010` does not satisfy T01. Only T-namespace IDs count; `SPEC-001-N08` and `SPEC-001-R11` tags are ignored.

**Test source:** a file under one of these roots, skipping `node_modules`, `dist`, `build` and `.git`:
- `src/`, `app/`, `supabase/tests/`, `packages/`, `e2e/`, `.maestro/`

…whose repo-relative path matches one of:
- `/__tests__/`
- `\.test\.[cm]?[jt]sx?$`
- `^supabase/tests/.*\.sql$`
- `^(e2e|\.maestro)/.*\.(ya?ml|[jt]s)$`

`docs/`, `scripts/` and production files are excluded by construction. Export the predicate as `isTestSource(relPath)`.

**MUST rows inside a SHOULD row** (for example SPEC-001 R57 "MUST NOT list precise location") are governed by the row's level and are not counted. That belongs to the normative-prose gate (out of scope).
